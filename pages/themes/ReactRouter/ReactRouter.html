What is routing?

Routing is the process of determining what code to run when a URL is accessed.
It is essential for creating a single-page application with multiple views, enabling smooth navigation and a better user experience without full page reloads.

Introduction

React Router is a standard library for routing in React.
It enables the navigation among views of various components in a React Application, allows changing the browser URL, and keeps UI in sync with the URL.
Install React Router via npm or yarn.
This will add the React Router to your project dependencies.

                npm install react-router-dom
                # or
                yarn add react-router-dom

Key Concepts

Router: The <Router> component (usually <BrowserRouter> or <HashRouter>) wraps your application and provides the routing context for the components inside it. It replaces the <Switch> component from v5 and provides a more intuitive and declarative way to define nested routes.
Routes: The <Routes> component renders the first child <Route> that matches the current location. It is used to group <Route> elements and ensure that only one of them renders at a time.
Route: The <Route> component defines a mapping between a URL path and a component. When the URL matches the path specified in a <Route>, the corresponding component is rendered.
Outlet: The <Outlet> component is used in parent routes to render child routes. It serves as a placeholder for nested routes.
Link: The <Link> component is used to create navigable links within the application. It’s similar to an HTML <a> tag but without causing a full page reload.
NavLink: A <NavLink> is a special kind of <Link> that knows whether or not it is "active", "pending", or "transitioning".
Hooks: useHistory, useLocation, useParams, useRouteMatch: These are hooks provided by React Router for accessing and manipulating the router state and URL parameters.

Basic Usage

Wrap your app with BrowserRouter and define routes using Route.
The BrowserRouter component should wrap your entire application.
The Link component is used to create links to different routes defined in your application.

                import { BrowserRouter as Router, Routes, Route, Link } from 'react-router-dom';
                import About from "./components/Router/about";
                import Home from "./components/Router/home";
                import Contact from "./components/Router/contact";


                function App() {
                    return (
                        <Router>
                            <nav>
                                <ul>
                                    <li><Link to="/">Home</Link></li>
                                    <li><Link to="/about">About</Link></li>
                                    <li><Link to="/contact">Contact</Link></li>
                                </ul>
                            </nav>
                            <Routes>
                                <Route path="/" element={<Home />} />
                                <Route path="/about" element={<About />} />
                                <Route path="/contact" element={<Contact />} />
                            </Routes>
                        </Router>
                    );
                }

                export default App

Nested Routing

Nested routing allows you to render sub-routes inside a parent route.

                import React from 'react';
                import { BrowserRouter as Router, Route, Routes, Link, Outlet, useParams } from 'react-router-dom';
                import "./App.css";

                const Home = () => <h2>Home</h2>;
                const About = () => <h2>About</h2>;
                const Users = () => (
                  <div>
                    <h2>Users</h2>
                    <nav>
                      <ul>
                        <li><Link to="1">User 1</Link></li>
                        <li><Link to="2">User 2</Link></li>
                      </ul>
                    </nav>
                    <Outlet /> {/* Placeholder for nested routes */}
                  </div>
                );
                const User = () => {
                  const { id } = useParams();
                  return <h2>User ID: {id}</h2>;
                };

                function App() {
                  return (
                    <Router>
                      <div>
                        <nav>
                          <ul>
                            <li><Link to="/">Home</Link></li>
                            <li><Link to="/about">About</Link></li>
                            <li><Link to="/users">Users</Link></li>
                          </ul>
                        </nav>

                        <Routes>
                          <Route path="/" element={<Home />} />
                          <Route path="/about" element={<About />} />
                          <Route path="/users" element={<Users />}>
                            <Route path=":id" element={<User />} />
                          </Route>
                        </Routes>
                      </div>
                    </Router>
                  );
                }

                export default App;
